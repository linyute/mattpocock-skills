# 僅在強依賴項中明確指向 `/setup-matt-pocock-skills`

工程技能依賴於透過 `/setup-matt-pocock-skills` 初始化的各儲存庫設定（問題追蹤器、分類標籤詞彙表、領域文件配置）。某些技能如果沒有該設定就無法發揮實質作用：它們必須發布至特定的問題追蹤器或套用特定的標籤字串。其他技能則僅使用它來讓輸出更精準（詞彙表、ADR 感知），在缺少時也能優雅降級。

我們將這些技能分為**強依賴**（hard-dependency）與**弱依賴**（soft-dependency）技能：

- **強依賴**（`to-tickets`、`to-spec`、`triage`）：包含明確的一句話：_「…應已提供給您；如果沒有，請執行 `/setup-matt-pocock-skills`。」_ 若沒有該對應關係，輸出結果將會是錯誤的，而不僅僅是模糊不清。
- **弱依賴**（`diagnose`、`tdd`、`improve-codebase-architecture`）：僅在模糊的敘述中引用「專案的領域詞彙表」與「您所接觸領域中的 ADR」。如果文件不存在，該技能仍然可以運作；只是輸出較不精準。

這種區分使弱依賴技能保持精簡的 Token 消耗，並避免將設定指示盲目套用到非關鍵負載之處。
