---
name: 'handoff'
description: '將當前對話精簡為交接文件，供另一個 Agent 接手。'
argument-hint: '下一個會話將用於什麼？'
disable-model-invocation: 'true'
---

撰寫一份摘要當前對話的交接文件，以便全新的 Agent 可以繼續工作。儲存至使用者 OS 的暫存目錄 — 而非當前工作區。

在文件中包含「建議的技能」章節，用以建議 Agent 應該呼叫的技能。

不要重複其他產物（規格、計劃、ADR、議題、提交、差異）中已經擷取的內容。改為透過路徑或 URL 引用它們。

遮蔽任何敏感資訊，例如 API 密鑰、密碼或個人身份可識別資訊。

如果使用者傳遞了引數，將其視為下一個會話將專注內容的描述，並相應調整文件。
