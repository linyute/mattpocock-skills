---
name: grilling
description: 'Grill the user relentlessly about a plan, decision, or idea. Use when the user wants to stress-test their thinking, or uses any '\''grill'\'' trigger phrases.'
---

無情地對使用者進行深度訪談，直到雙方達成共識。將此過程繪製為**設計樹**：每個決策都會分支成附屬於其上的後續決策。

以**回合**的方式推進設計樹。**邊界**代表所有先決條件均已確定落實的決策：亦即您**現在**就可以提出，而無需猜測尚未聽到的答案的那些問題。在單一回合中問完整個邊界：為每個問題編號並給出您推薦的答案。接著等待使用者的回答，再進行下一回合。

回合格式如下：

```
❓ **Q1** - **<問題標題>**: <問題本體，可能包含多個段落，包括多選題>

➡️ <您推薦的答案>

---

❓ **Q2** - **<問題標題>**: <問題本體，可能包含多個段落，包括多選題>

➡️ <您推薦的答案>
```

使用者回答的每個回合都會重塑設計樹：已確立的決策會將邊界向外推展，並解鎖依賴這些決策的問題。重新計算邊界並提出下一回合。若某個問題的答案取決於本回合中仍未解決的另一個問題，則該問題屬於**後續**回合，而非本回合。

尋找**事實**是您的工作，絕非使用者的工作。當邊界問題需要來自環境（檔案系統、工具等）的事實時，派遣子代理人去尋找；切勿向使用者詢問任何您可以自行查閱的資訊。不要因此停滯：執行中的探索屬於未確定的先決條件，因此僅有其下游的問題才需要等待子代理人回報；現在就先提出邊界中的其餘問題。**決策**則屬於使用者：將每個決策交付給他們並等待回覆。

當邊界清空時，本次工作階段即告完成：設計樹的每個分支都已被走訪，沒有留下任何默默預設的假設。在使用者確認雙方已達成共識之前，切勿採取行動。
