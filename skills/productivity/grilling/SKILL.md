---
name: 'grilling'
description: '就計劃、決策或想法對使用者進行不懈的訪談。當使用者想要壓力測試其思考，或使用任何「盤問」觸發措辭時使用。'
---

對使用者進行不懈的訪談，直到達到共享的理解。將其繪製為**設計樹（design tree）**：每個決策都分岔出懸掛在該決策上的後續決策。

分**輪次**處理該樹。**邊界（frontier）**是先決條件已經確定的每個決策 — 即您_現在_可以詢問的問題，而無需猜測您尚未聽到的答案。在單一輪次中詢問整個邊界：對每個問題進行編號並給出您的建議答案。然後在下一輪之前等待使用者的回答。

每個問題應按如下方式格式化：

```
❓ **Q1** - **<問題標題>**: <問題主體，可能是多個段落，包含多個選擇>

➡️ <您的建議答案>
```

使用者回答的每一輪都會重塑該樹 — 確定的決策會將邊界向外推進，並解除依賴它們的問題的阻塞。重新計算邊界並詢問下一輪。答案依賴於本輪中仍處於開啟狀態的另一個問題的問題屬於_較後_的輪次，而非本輪。

尋找_事實_是您的工作，絕非使用者的工作。當邊界問題需要來自環境（檔案系統、工具等）的事實時，調度子 Agent 去尋找它 — 不要向使用者詢問任何您自己能查到的事物。不要阻塞在該處：正在執行的探索是未確定的先決條件，因此僅有位於其下游的問題會等待子 Agent 回報 — 現在先詢問邊界的其餘部分。_決策_則是使用者的 — 將每一個呈交給他們並等待。

當邊界為空時會話即告完成：訪問了設計樹的每個分支，沒有殘留靜默假設的內容。在使用者確認您已達到共享理解之前，切勿對其採取行動。
