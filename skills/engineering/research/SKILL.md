description: '針對高信任度的主要來源調查問題，並將結果記錄為儲存庫中的 Markdown 檔案。當使用者希望研究某個主題、收集文件或 API 事實，或將閱讀的繁重工作委派給背景 Agent 時使用。'
---

啟動一個**背景 Agent**來進行研究，以便在它閱讀時您可以繼續工作。

它的工作：

1. 針對**主要來源**（官方文件、原始碼、規格、第一方 API）調查問題 — 而非對它們的次要撰寫文章。追溯每個主張至擁有它的來源。
2. 將結果寫入單一 Markdown 檔案，引用每個主張的來源。
3. 將其儲存至儲存庫中已保留此類筆記的位置；符合現有慣例，如果沒有，請將其放在合理的位置並說明路徑。
