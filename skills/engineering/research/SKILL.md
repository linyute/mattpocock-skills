description: '對照高可信度的一手資料來源調查問題，並將研究結果擷取為儲存庫中的 Markdown 檔案。當使用者需要對某個主題進行研究、收集文件或 API 事實，或將閱讀工作委派給背景代理時使用。'
---

啟動一個**背景代理**來進行研究，以便在其閱讀時您可以繼續工作。

其工作為：

1. 對照**一手資料來源**（官方文件、原始程式碼、規格書、第一方 API）調查問題，而非二次撰寫的文章。追蹤每個論點直到擁有它的來源為止。
2. 將研究結果寫入單一 Markdown 檔案，並引用每個論點的來源。
3. 將其儲存至儲存庫中既有存放此類筆記的位置；符合現有慣例，若沒有現有慣例，則將其放置在合理的位置並說明位置。
