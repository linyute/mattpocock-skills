# 分流標籤

這些技能以五種標準分流角色的術語表達。此檔案將這些角色對應至本儲存庫 issue tracker 中實際使用的標籤字串。

| mattpocock/skills 中的標籤 | 我們 tracker 中的標籤 | 意義                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 維護者需要評估此 issue                   |
| `needs-info`               | `needs-info`         | 等待回報者提供更多資訊                   |
| `ready-for-agent`          | `ready-for-agent`    | 規格完整，已準備好供離線 Agent 處理      |
| `ready-for-human`          | `ready-for-human`    | 需要人工實作                             |
| `wontfix`                  | `wontfix`            | 不會進行處理                             |

當技能提到某個角色時（例如「套用 AFK-ready 分流標籤」），請使用此表格中對應的標籤字串。

編輯右側欄位以符合你實際使用的任何字彙。
