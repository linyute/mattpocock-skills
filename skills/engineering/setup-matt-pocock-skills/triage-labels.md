# 分揀標籤

技能以五個規範分揀角色的角度進行交流。此檔案將這些角色對映至此儲存庫議題追蹤器中使用的實際標籤字串。

| mattpocock/skills 中的標籤 | 我們追蹤器中的標籤 | 意義 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage` | `needs-triage` | 維護者需要評估此議題 |
| `needs-info` | `needs-info` | 等待回報者提供更多資訊 |
| `ready-for-agent` | `ready-for-agent` | 規範完整，準備好供離線 Agent 使用 |
| `ready-for-human` | `ready-for-human` | 需要人類實作 |
| `wontfix` | `wontfix` | 將不予採取行動 |

當技能提到某個角色時（例如「套用 AFK-ready 分揀標籤」），請使用此表中的相應標籤字串。

編輯右側欄位以符合您實際使用的任何詞彙。
