---
name: 'resolving-merge-conflicts'
description: '當您需要處理解決進行中的 git merge/rebase 衝突時使用。'
---

1. **檢視 merge/rebase 的當前狀態**。檢查 git 歷史紀錄以及發生衝突的檔案。

2. **尋找每個衝突的主要來源**。深刻理解為什麼進行每次變更，以及原始意圖是什麼。閱讀提交訊息、檢查 PR、檢查原始議題/票券。

3. **解決每個區塊（hunk）。** 在可能的情況下保留雙方的意圖。在不相容之處，選擇符合 merge 聲明目標的方向並註明權衡。**切勿**發明新行為。始終進行解決；絕不 `--abort`。

4. 探索專案的**自動化檢查**並執行它們 — 通常是型別檢查，然後是測試，最後是格式化。修復 merge 所損壞的任何內容。

5. **完成 merge/rebase。** 暫存所有內容並提交。如果是 rebasing，請繼續 rebase 流程，直到所有提交都已被 rebase。
