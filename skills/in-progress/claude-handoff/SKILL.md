---
name: 'claude-handoff'
description: '將目前對話交接給全新的背景代理人，以立即接手工作。'
argument-hint: '下一個工作階段將用於什麼目的？'
disable-model-invocation: true
---

撰寫目前對話的交接摘要，讓全新的代理人可以繼續工作。不儲存摘要，而是啟動一個背景代理人，並以此摘要作為其提示種子：`claude --bg --name "<descriptive name>" "<handoff summary>"`。它會在目前工作目錄中啟動並立即返回；使用者可透過 `claude agents` 進行管理。

務必使用具描述性的名稱傳入 `-n`/`--name`（例如 `--name "Fix login bug"`）；它會設定工作清單、工作階段選擇器和終端機標題中顯示的名稱。

在摘要中包含「建議的技能」章節，指明下一個代理人應呼叫 Skill 工具使用哪些技能。

不要重複已在其他產物（規格、計畫、ADR、問題、提交、差異比較）中記錄的內容。改為透過路徑或 URL 引用它們。

遮蓋任何敏感資訊，例如 API 金鑰、密碼或個人識別資訊，因為此摘要會成為該代理人的提示。

如果使用者傳入了引數，請將其視為下一個工作階段焦點的描述，並相應調整摘要。
