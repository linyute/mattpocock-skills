# 雜項（Misc）

我隨身攜帶但很少使用的工具 — 未在外掛程式中推廣。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)** — 設定 Claude Code Hook 以在危險的 Git 命令（push、reset --hard、clean 等）執行前阻止它們。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** — 將測試檔案從 `as` 型別斷言遷移至 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)** — 建立帶有章節、問題、解答與解釋器的練習目錄結構。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** — 設定帶有 lint-staged、Prettier、型別檢查與測試的 Husky pre-commit Hook。
